# Sidecar A–E 同起点短训：最终误差、Loss与机制综合对比

分析时间：2026-10-28T02:38:31.562355+00:00。本轮仅CPU复核已保存日志/诊断并生成文档与图表；不改代码、训练参数、数据或GPU进程。此前中期文档的“E尚未完成”属于历史快照，本报告使用五组最终1000次更新结果。

## 1. 结论先行

**A是当前综合最稳的参照，但并非每一项最优；C有明确的解冻稳定化收益，却还没有证明动作/闭环整体超过A；B的早期1% EA共享梯度明显拖慢关系与计划学习；D没有通过提高Write LR增强有效写回；E保留了部分短期位置与Randomized FM收益，但未形成完整动作序列优势。**

五组中，没有一个候选在训练后段Action、两域32步位置、旋转、夹爪以及固定Action FM上全面领先A。C后来又多训1K的结果也必须纳入判断：动作位置进步明显，但同预算仍有Clean和固定FM短板，不能再把“C更平稳”直接说成“C已涨点”。
