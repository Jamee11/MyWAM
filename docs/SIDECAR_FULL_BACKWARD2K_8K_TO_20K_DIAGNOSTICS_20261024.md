# Full-backward warmup2K：8k/12k/16k/20k固定输入动作与写回趋势

## 完成结论（2026-10-24）

**16k→20k有实际动作精度进展，不只训练loss下降；真实写回继续收缩，但20k仍有小幅正收益。**
不能说所有指标单调改善：20k Randomized前8步位置仍差于12k/16k，Clean夹爪也未随训练改善。
因此继续当前训练，不改gate/loss；保留12k作为Randomized短时参照，24k再确认。

16k与20k各50组生成、32组FM全部完成；与12k的50输入、32样本/噪声记录完全匹配，
Full重复逐位一致、Off实际delta全零、FM前后参数指纹一致。新旧配置/统计/契约逐字节一致。
四点前8/32步误差均从原始保存动作重算；32步位置/旋转和8/32步夹爪复现既有记录。
两个最终进程3703094/3703095已退出，GPU6回到本轮前约425MiB；GPU5外部占用保留，
训练3501138及0–3 GPU作业保持。未新启停任何4090评测或其他模型部署。

### 5. 决策与下一步

1. 继续当前训练，不在run中途改gate/loss。20k全32步位姿明显好于16k，支持继续验证。
2. 保留12k和20k，不仅按训练loss选checkpoint：20k长时位姿更好，12k Random短时位置更好。
3. 24k保存后复用本协议确认，重点看Random前8步XYZ、Clean夹爪、真实write-r及Full/Off收益；
   若长时持续改善但短时不改善，先分析预测时间范围/执行与任务窗口，不先强行放大gate。
4. 当前写回不是零作用，但局部收益约亚毫米，不足以证明整体Sidecar优于matched Vanilla。
   结合另一会话的20k闭环结果再判断成功率；本轮不重复派发闭环或扩展梯度研究。

## 解释边界

六条专家轨迹的重叠窗口不是大量独立episode；固定噪声有利于配对但不估计多seed波动。
仅四个checkpoint测点，不能推出连续训练全程单调；范数比不等于hidden语义贡献百分比。
Full/WriteOff只隔离当前checkpoint的即时写回，不等同从头训练无Sidecar模型。
FM有带噪GT未来视频，生成仅用当前观测，两者不能混为同一泛化指标。
相对专家误差不能替代闭环SR；near/模拟执行差异仍需闭环核实。原训练趋势报告中的
“16k/20k尚未测”属于当时快照，本轮完成后应以本报告新增固定输入测量为准。
