# 原始 warmup2K→10epoch 与 XA：训练趋势、配对诊断和下一步

记录时间：2026-10-31 UTC。范围：只读日志、已有离线生成结果及实现分析；没有修改模型、训练配置或启停 GPU 实验。

## 结论

XA 正在正常收敛，但目前不能说它已提高外观鲁棒性。其训练 loss 优势主要在 Video，Action 优势很小；alignment loss 下降没有对应所有外观条件的动作稳定性提升。先完成当前 XA，并评估 15K/20K/最终权重；若当前现象延续，下一训练候选优先恢复成功基线的完整 PatchWAM 并保留当前 XA，其余配置保持，不同时提高 alignment 系数或 gate。

当前不能宣称 XA 劣于最终基线：XA 只有 10K 的已完成诊断，基线已训练 21480 步，预算不等。最终同预算闭环结果决定是否执行下一候选；若 XA 已明显胜出，先保留该方案，不必立即再训练。

## 同 optimizer update 的 loss 比较

日志均为 rank0，不是八卡聚合的独立验证 loss。XA 先对同一次更新的两个微步取平均；grad_norm 只用同步更新的第二微步，避免把正常的非同步零值混入。两个日志中记录的数值均有限。XA 的总 loss 额外含 alignment，故比较 Video/Action/EA 分项以及扣除 XA 的基础 loss。

最近共同窗口：12423–13422，共1000更新，均值：

|---|---:|---:|---:|
|基础总 loss|0.167346|0.150143|-10.28%|
|Video loss|0.118421|0.101511|-14.28%|
|Action loss|0.00055264|0.00053363|-3.44%|
|EA loss|0.048373|0.048098|-0.57%|

吞吐来自日志微步耗时相加，可能不含全部保存/等待开销。按剩8058更新和近1000步速度，约13.4小时计算时间；不是承诺完成时间。

两版持续正常下降，XA 的 Action 优势约1%–4%，没有数量级改善。基础总 loss 约98%的下降差额来自 Video，而两版增强强度不同，不能据此把 Video 降幅算成 alignment 的因果收益。XA 关闭 Hue/AdaIN/FFT，亮度、对比度、噪声等幅度更小；重建目标/输入难度可能随之变化。

EA 总量接近平平台不代表所有辅助任务停止学习：最新 Ground 原始约3.391，乘 .5×.025 后约.04239，已占EA约88%；Plan/Relation仍下降。不要按未加权分项大小直接调整总权重。

## Alignment 的实际作用量级

|窗口|XA raw|加权XA|日志 XA/EA 均值|
|---|---:|---:|---:|
|201–1000|0.08251|0.02548|43.9%|
|2001–5000|0.01037|0.005186|10.1%|
|5001–10000|0.005314|0.002657|5.40%|
|12423–13422|0.003497|0.001748|3.64%|

后期系数已封顶 .5，目标80%没有实现。但不建议为了凑到80%直接把系数提高到约11：总梯度范数已经约2.23倍基线。这个范数含新增 projector 且没有分解到共享 Action 参数，不能断言 XA 本身的梯度是 EA 几倍，也不能断言冲突；需要在相同 batch/timestep/noise 上分别测 Action FM、EA、XA 对相同参数组的梯度范数和方向。

实现是 projector(student action层8)→stop-gradient EMA teacher action层20 的 cosine 对齐，训练误差也可能被 projector 吸收。raw下降不证明动作输出不变性，更不证明发生表示坍塌。EMA .9999 的半衰期约6931更新：10K仍保留约36.8%初始参数权重，13422约26.1%；这是慢teacher的属性，不是已确认故障。没有按噪声档位分解的 held-out alignment 与梯度数据，相关机制仍未验证。

## 已完成配对动作诊断

|指标|原基线最终21480|XA5000|XA10000|

|名义输入：对GT动作误差|12.90|18.83|16.22|
|名义输入：前8步GT误差|8.03|9.22|10.34|

|强光照：相对名义输入动作偏移|14.22|11.03|15.00|
|噪声+模糊：相对名义输入动作偏移|5.84|14.32|12.21|
|PatchWAM压力：相对名义输入动作偏移|6.44|8.16|9.68|
|强光照：对GT动作误差|25.29|22.57|26.94|
|噪声+模糊：对GT动作误差|16.63|25.43|25.01|

需要同时看偏移与GT误差，避免把输出恒定误当稳健。XA 5K→10K总体名义GT改善，但前8步恶化；不能只按32步均值挑权重。强光照平均偏移由11.03升到15.00，中位窗口亦由5.22升到8.00，不只是单一最大离群点；不过样本仍高度相关，不能推断总体显著性。原基线强光照均值受103.76mm最差窗口影响，中位数只有2.64mm，因此不能只用均值宣布XA优势。

Randomized噪声/模糊的GT误差：基线18.85mm、XA5K30.10mm、XA10K33.28mm；XA全域噪声漂移均值下降并没有覆盖这个退化。三个任务不足以外推100条件闭环。

隐藏层也未呈现“alignment loss越低，外观越不敏感”的简单关系：XA5K→10K，噪声条件未经过projector的层8相对L2由.02555到.02583，基本没改善；层20由.07129降到.04959，但仍高于原最终基线.03062。该隐藏量来自首个高噪声去噪步，受共用action noise影响，不等同训练XA target，也不能单独证明机制。

WriteOff分析：XA10K在弱光照、噪声、PatchWAM的Full对GT误差比关闭Write好约0.90–1.05mm，强光照反而略差约0.13mm。Sidecar没有完全失效，但不能说当前所有偏移问题都来自gate小。历史×2/5/10/100放大没有总体收益，当前不建议再硬调gate。

## 下一步安排建议（未执行）

1. 当前XA按原计划完成，不在中途改系数、增强或学习率。继续已有15K/20K/final配对诊断；既看全32步，也看前8步，分Clean/Randomized和扰动类型。
2. 先用XA20K/最终权重做与旧21480一致的闭环协议：同100个任务/域条件、同seed筛选、相同推理缓存/去噪/horizon/预算/成功判据；若基线另有补70扩展，保持30条共同前缀对比或为XA补同协议，不能把不同样本量/指令池当严格逐例配对。候选可先固定预先选定的困难任务，但最终用完整100条件检验。
3. 若最终仍表现为“普通输入尚可，噪声/强扰动退化”，下一训练优先 **原始warmup2K + 原成功版完整PatchWAM + 当前XA**：同起点、新optimizer、10epoch21480、LR与global256不变，8×16acc2，8→20及EMA/.5上限保留，gate1，独立配置/输出，完成当前作业后只占8卡。只恢复增强这一因素，暂不同时升λ、改EMA或只训action。与当前XA比较增强因素；与旧成功基线比较XA组合的效果，但旧基线microbatch/acc不同、随机轨迹不同，仍非完美单变量重复实验。原完整增强的Hue/FFT可能改变颜色语义这一风险继续保留，不凭过去平均SR消除它。
4. 若目的是严格分离当前XA收益与“减弱增强”的收益，还缺 **当前中等增强但关闭XA** 的匹配对照（8×16acc2）。这是必须承认的归因缺口；目前不能拿warmup2K→XA10K的改善当XA收益。性能探索优先第3项；严格消融可在候选确认后补，不同时铺开多个8卡实验。
5. 只有在最终闭环显示XA有价值、且分组梯度诊断证实对Action的对齐信号不足时，才单独研究更高系数或后期系数日程；不要凭XA/EA标量比值强行追80%。若最终XA明显退化，则先补匹配no-XA对照/机制诊断，不继续叠大权重。

本次不新增架构、训练或部署变更。不存在当前已证明的最优XA权重或闭环增益结论。
