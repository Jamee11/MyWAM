### 2. 写得弱一些，并不意味着Action更差

同checkpoint Full−WriteOff的XYZ误差差值，负数表示写回有益（mm）：

| 子集 | 8K写回收益 | 12K写回收益 |
| --- | ---: | ---: |
| Clean全32步 | −0.4657 | −0.1795 |
| Randomized全32步 | +0.7917（变差） | −0.2369（改善） |

生成动作Full的绝对误差（mm）：

| 子集/时间范围 | 8K | 12K |
| --- | ---: | ---: |
| Clean前8步 | 7.6377 | 6.8368 |
| Randomized前8步 | 13.2737 | 8.7570 |
| Clean全32步 | 10.1209 | 11.1658 |
| Randomized全32步 | 21.8283 | 15.6497 |

因此Randomized明显改善，Clean全32步反而略差；不能说所有指标随训练单调改善。
更不能将“写回下降”解释为成功率下降，或反过来把变弱直接解释为学会精准写入。

### 3. 训练趋势解释与建议

日志显示write beta绝对值在前2000次优化更新期间增大，WAM参与参数更新后下降；
保存快照截至micro14621/opt7310，beta进一步降至−.00623/−.00662/−.00693。
读取alpha同时上升。记录的是有符号混合系数，负号不是有害标签，亦不能用初始化
零gate推断整段无效。真实写回只有8K/12K两个固定输入测点，不证明连续单调下降。

目前不支持“写回正在失效”或“必须强行增大gate”。建议继续原训练，在后续checkpoint
复用相同强度/FullOff协议观察是否趋于稳定；若真实残差持续靠近零且配对收益消失，
再讨论结构或训练目标。若离线收益保持，则优先做同seed配对闭环，而不是先改初始化。
无法据本轮区分“主干吸收了信息”与“模型压低了冗余/不利写回”，需要额外对照。

## 实验目的与身份

用户要求判断随训练进行gate及实际写回影响增强还是减弱，而不是用gate代替真实残差。
同一run：`outputs/sidecar/aloha50_full_backward_warmup2k_10epochs_20261022T134733Z/2026-10-22_13-54-18`。
8K为4000次Sidecar更新、2000次WAM更新；12K为6000次Sidecar更新、4000次WAM更新。
前2000次优化更新正常读写/反向，仅跳过WAM参数、Adam状态和衰减更新。
这不是之前isolation warmup，未修改正在运行的训练。

## 匹配协议与产物

复用12K完整诊断入口、相同25个GT窗口（24held-out来自六条专家episode，另一个训练内控制）、

prepared输入与噪声的Action FM配对。不重复与本问题非必要的32批梯度分析。
直接测hidden、投影输出、beta乘后原生dtype残差、真实加法delta的L2/RMS和元素变化率。
真实写回比为逐前向`||hidden_after-hidden_before|| / ||hidden_before||`再平均。
