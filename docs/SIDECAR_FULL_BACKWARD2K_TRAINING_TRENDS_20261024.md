# 新 full-backward warmup2K：16k/20k 与既有动作诊断的综合分析

> 后续更新：16k/20k固定输入动作与真实write-r现已补齐，见
> [四checkpoint完整诊断](SIDECAR_FULL_BACKWARD2K_8K_TO_20K_DIAGNOSTICS_20261024.md)。
> 20k全32步位姿改善，但Random前8步位置未超过12k，Clean夹爪亦非单调改善；
> 实际write-r继续下降且Full/Off收益仍存在。下文“尚未完成”保留为05:23时的历史快照，
> 不是最新实验状态。本页原训练曲线与数值不变，不将离线指标等同闭环SR。

时间：2026-10-24 UTC；训练日志快照 05:23:54 UTC，四 rank 共同截止 micro21297/optimizer10648。本次仅分析 CPU 日志与 checkpoint 内标量，未加载 GPU 模型、未改训练、未启停实验。

## 1. 当前结论

**训练拟合仍持续改善，没有看到后期数值发散；读取系数增大、写回系数减小的分化延续到 16k/20k。** 但此前 8k/12k 的固定输入实验已说明：写回更强不必然动作更准确。当前不能只因 gate 缩小就判 Sidecar 失效，也不能因 Action training loss 下降就宣称成功率提高。

相比旧版本，新 warmup 已有“真实写入可测且对部分动作指标有帮助”的证据；尚未证明最终策略优于 matched Vanilla。**现在应重点补 20k 的固定输入动作/真实写回诊断与闭环，而非继续改网络或强行增大 gate。**

## 2. 16k 与 20k：训练 loss 并未停滞

各列取对应 checkpoint 前 1000 个 microsteps 的均值；16k/20k 分别为 8000/10000 次 optimizer updates。前 2000 次 WAM 未更新，因此 WAM 实际更新分别为 6000/8000 次。所有训练 loss 都来自 Clean 训练分布，不是 Randomized validation。

| 指标 | 8k | 12k | **16k** | **20k** | **16k→20k** |
| --- | ---: | ---: | ---: | ---: | ---: |
| Total | 0.174515 | 0.160758 | **0.150531** | **0.143790** | −4.48% |
| Action | 0.00185343 | 0.00126473 | **0.00096202** | **0.00077542** | **−19.40%** |
| Video | 0.120687 | 0.109361 | **0.100267** | **0.094316** | −5.94% |
| EA（实际加权） | 0.051974 | 0.050132 | **0.049302** | **0.048699** | −1.22% |
| Ground（原始分项） | 3.415975 | 3.404735 | **3.398448** | **3.394329** | −0.12% |
| Relation（原始分项） | 0.038887 | 0.023767 | **0.016408** | **0.011322** | **−31.00%** |
| Plan（原始分项） | 0.185573 | 0.124359 | **0.097158** | **0.076870** | **−20.88%** |

解释：

- Action、Relation、Plan 在 16k→20k 仍有明显训练拟合进展，当前没有仅凭训练曲线提前停止的理由。
- Ground/EA 看起来平，不等于所有辅助能力停止学习。20k 的 EA 数值中 Ground 占 87.12%、Deep 占 8.81%、Plan 占 3.95%、Relation 占 0.12%；较大的近常量项掩盖了 Relation/Plan 的下降。
- Ground 使用高斯软标签空间交叉熵，包含目标熵下界；此前同数据契约抽样目标熵约 3.3817。当前 Ground≈3.3943 接近此数值，但不能用非同 batch 的均值相减当作精确 KL，更不能判定定位完美。下一步应看 held-out 定位指标，不要求该 loss 归零。
- 上述百分比是损失值分解，不是梯度贡献；不能据它直接认定 Ground 对优化的贡献为 87%。

## 3. Gate 到 16k/20k 的真实变化

16k/20k 的表中系数已直接读取各自 safetensors 标量，与训练日志对应值一致；没有将旧 joint20k 或 isolation24k 混入本 run。

| 系数 | warmup 结束 4k | 8k | 12k | **16k** | **20k** |
| --- | ---: | ---: | ---: | ---: | ---: |
| Read α7 | 0.03906 | 0.04858 | 0.05688 | **0.06128** | **0.06445** |
| Read α15 | 0.04468 | 0.07275 | 0.09180 | **0.10205** | **0.10938** |
| Read α23 | 0.01263 | 0.01904 | 0.02515 | **0.02759** | **0.02881** |
| Write β7 | −0.02734 | −0.01367 | −0.00818 | **−0.005493** | **−0.003754** |
| Write β15 | −0.03931 | −0.01819 | −0.00989 | **−0.005554** | **−0.003708** |
| Write β23 | −0.03735 | −0.01770 | −0.00989 | **−0.005676** | **−0.004150** |

16k→20k，三层 |β| 又下降 **31.67% / 33.24% / 26.88%**；α继续增大。相邻窗口的变化速度比刚解冻时小，但尚未稳定为常数，也不能据此外推最终值。

**可确认的是：主干参与更新之后，优化过程持续减小写回混合系数，同时增大 Read 混合系数。** 不能据此直接确认“主干吸收了关系知识”“Sidecar 被拒绝”或“视觉依赖增强”：这些解释需要实际特征尺度、梯度和干预实验。

这也不是单纯 weight decay 的自然缩小：Sidecar LR 最高 5e-5、weight decay=.01，在 2K→10K 共8000次更新中，单独衰减至多约 **0.40%**；实际 |β| 缩小约 86%–91%。梯度/Adam 更新是必须考虑的因素，不能将下降全归给衰减。学习率下降本身只改变更新步长，不会自动把参数拉向零。

负 β 不是负作用标签，α=.109 也不等于读取了 10.9% 的视觉信息；实际残差取决于投影输出和原 hidden 的尺度。

## 4. 结合动作误差：强写回、低训练 loss 与控制收益要分别看

动作是连续输出，本项目目前没有一个可以统称为“Action 准确率”的百分数。应分别看原训练 Action FM loss、相对专家动作的 XYZ/旋转/夹爪误差，以及闭环任务成功率。

以下为**已完成**的同 run、同输入/噪声 8k/12k 离线诊断，16k/20k 尚没有相同协议完成的结果，不能从日志补算：

| 指标 | 8k | 12k | 结论 |
| --- | ---: | ---: | --- |
| 三层实际 hidden 写回比 | 1.108% / 1.589% / 2.082% | 0.612% / 0.653% / 0.899% | 写回确实减弱，不只 β 变小 |
| Clean 前8步 XYZ（mm） | 7.638 | 6.837 | 实际先执行的一段更接近专家 |
| Randomized 前8步 XYZ（mm） | 13.274 | 8.757 | 明显改善 |
| Clean 全32步 XYZ（mm） | 10.121 | 11.166 | 反而变差，不能声称所有动作指标改善 |
| Randomized 全32步 XYZ（mm） | 21.828 | 15.650 | 明显改善 |
| Clean Full−Off 全32步 XYZ（mm） | −0.466 | −0.180 | 写回局部收益减小 |
| Randomized Full−Off 全32步 XYZ（mm） | +0.792（有损） | −0.237（有益） | 写回变弱的同时，收益方向转正 |
| 32批配对 Action FM：Full相对Off | −11.94%，27/32更好 | −5.72%，29/32更好 | 都有局部帮助；收益大小不单调 |

12k 的 Clean 旋转/夹爪没有同步改善。其 Full 全32步绝对误差仍大于旧 joint42960 的 6.347/12.609mm，但训练预算、LR与EA权重不同，不能作纯 warmup 优劣判定。

由此得到两个相容的判断：

1. **新方案已比旧微弱写回更明确地影响动作，并在12k离线配对中表现出部分正收益。** 不能继续笼统称“Sidecar 完全没用”。
2. **直接贡献仍有限、指标间有取舍。** 更大的 β/实际残差不等于更好动作；训练 Action loss 下降也未保证所有 held-out 时间范围误差下降。

FM 配对使用带噪专家未来视频，生成只使用当前观测，两者不等价；不同有效动作轨迹也可能完成同一任务，所以专家轨迹误差仍不能替代闭环 SR。

## 5. 梯度问题是否改善

12k 已完成的新梯度诊断显示：Clean 共享模块 EA/Action 范数比约112–236倍，Randomized约1914–3284倍；相比旧模型显著缩小，但辅助主导仍存在。EA→Write投影为结构性零，不是断图。

**16k/20k 尚未完成同协议梯度测量，不能声称这个比例继续改善或恶化。** 不能用 Action loss 数值下降来反推 Action 梯度更大或更小；也不能将 |β| 下降直接解释成动作梯度消失。

这意味着 warmup 初步解决了旧模型“难以形成有效写入”的现象，但是否解决了稳定期共享表征主要服务辅助任务的问题，还没有充分证据。

## 6. 数值健康与当前阶段

四 rank 日志均连续，已读指标全部有限；共同区间各 rank metric 最大差为0，属于已聚合日志，不能把四份视为四次独立训练。Total−Action−Video−EA 的最大残差约5.22e-8，与真实加权公式一致。

前2K期间 Action训练loss下降、Video约0.21基本不动；解冻后Action与Video均快速下降，再进入缓慢改善阶段。WAM首次更新有过梯度尖峰，后来恢复；16k和20k对应最近窗口的更新步grad norm保持较低，没有后期爆炸迹象。非更新micro的grad_norm=0是accumulation=2日志行为，不能当作断梯度。

20k的WAM日志LR约6.02e-5，比16k的7.44e-5低，仍非训练末端。现有曲线属于训练拟合，缺少与每个checkpoint同步的独立泛化曲线，无法判断最佳checkpoint或排除过拟合。

## 7. 下一步：优先20k，24k作时间趋势确认

1. **继续当前训练。** 16k→20k仍有进展，不因gate下降停掉，也不在run中途改loss/初始化。无需等训练结束才看20k；已保存20k就是当前最合适的机制与闭环对象。
2. **补20k同协议离线诊断。** 复用既有25窗口/32FM输入，优先测实际写回、Full/Off，以及前8步/全32步XYZ、SO(3)、gripper。与8k/12k拼成同协议趋势。24k保存后再做一个后期测点；只有16k和20k权重文件，不等于已经完成这两点的动作精度诊断。
3. **闭环优先于继续扩大梯度研究。** 已有20k独立评估准备记录，避免重复启动；从同seed Full/Off及matched Vanilla固定任务比较，重点看Randomized与关键失败。30条/条件的筛选结果应保留分母和不确定性，不能冒充100条精度。
4. **设置一个明确决策点。** 若20k绝对动作误差改善且Full/Off收益保留，继续正式评测，不改Gate；若训练loss下降但held-out误差或闭环不改善，先查泛化/执行差异；若实际写回继续收缩且配对收益消失，再考虑Stage2 EA梯度路由的单变量短对照。若收益保持，即使gate继续下降也不应人为放大。
5. **LR ramp不是当前run的紧急修复。** 解冻瞬态已过去且恢复稳定，它只作为未来独立分叉的稳定性候选；不与EA heads-only、初始化或新几何loss一起叠加。
